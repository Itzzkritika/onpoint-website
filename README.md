## 🗺️ Features

- **Interactive Trip Meter** — Pick a destination, adjust monthly spend, watch the progress ring animate in real-time
- **Social Share Card Creator** — Generate aesthetic Instagram-ready "Trip Progress Cards"
- **Before/After Transformation** — Toggle between old rewards experience vs Onpoint
- **Animated Hero** — Particle canvas, floating phone mockup, real-time toast notifications
- **Campaign Strategy** — 3-phase "Side Quest Fund" activation plan
- **Gen Z Insights** — Animated data visualisations with real market research
- **Mobile Responsive** — Full hamburger nav, adaptive layout for all screen sizes

## 📱 The Strategy: TRIP IN PROGRESS

Instead of making users think about accumulating abstract reward points — make them think about the **destination they want to visit**.

| Pillar | Description |
|--------|-------------|
| 🗺️ **Pick Your Next Trip** | Users choose a dream destination as their goal |
| 📊 **See Every Step Count** | Every eligible purchase updates a visual progress meter |
| 🔍 **Trust the Numbers** | Clear earning rates, 1 Onpoint = ₹1 value, zero hidden fees |
| 🌐 **Make Progress Social** | Share aesthetic progress cards on Instagram |
